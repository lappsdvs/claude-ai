Aktiviti berkumpulan

Workshop Hands-On Menggunakan ChatGPT

Empat kumpulan membina jenis mini web app yang sama menggunakan jadual, peraturan perhatian dan graf yang berbeza. Semua bahan latihan menggunakan data simulasi.

⏱️ Anggaran keseluruhan: 75 minit
👥 45 minit kerja kumpulan
🎤 4 × 5 minit pembentangan
💬 Akaun ChatGPT
💡

ChatGPT ialah platform utama demonstrasi. Akaun percuma boleh digunakan, tertakluk pada had semasa. Fasilitator menggunakan ChatGPT Plus; ciri yang tersedia mungkin berbeza mengikut akaun.

ChatGPTOpenAI ClaudeAnthropic · alternatif GeminiGoogle · alternatif NotebookLMGoogle · alternatif dokumen

Tak ada akaun ChatGPT? Ikut demonstrasi utama bersama fasilitator atau gunakan salah satu platform alternatif untuk membandingkan hasil.

01 · Arahan umum

Cara semua kumpulan bekerja

Matlamatnya bukan mendapatkan jawapan pertama yang cantik, tetapi menghasilkan output yang boleh disemak dan dipertanggungjawabkan.

💬

Mod Akaun Free — maksimum satu prompt utama dan satu prompt pembetulan. Gunakan satu prompt tambahan hanya jika benar-benar perlu.

📋

Tiada muat naik fail diperlukan. Salin prompt lengkap kumpulan, tampal dalam satu chat ChatGPT dan hantar. Butang Salin Jadual digunakan untuk eksperimen data atau prompt pembetulan.

⏱️

Pembahagian masa

  • 45 minit kerja kumpulan, termasuk ChatGPT dan NotebookLM
  • 10 minit kemaskan hasil
  • 5 minit pembentangan bagi setiap kumpulan
  • 4 kumpulan = 20 minit pembentangan
  • Anggaran keseluruhan: 75 minit
👤

Agihkan peranan

Seorang operator ChatGPT bagi setiap kumpulan, bersama penyemak data, penguji web app dan pembentang.

🛡️

Peraturan

Gunakan data simulasi sahaja, satu prompt utama dan satu prompt pembetulan. Elakkan Deep Research dan jana semula berulang kali. Semak output—jangan terima bulat-bulat.

Tugas→Bina prompt utama→Output pertama→Semak→Prompt pembetulan→Output akhir→Bentang
02 · Kerangka mudah bengkel: T.K.T.F

4 Elemen Prompt yang Jelas

Prompt yang jelas membantu A.I memahami tugas, konteks, tujuan dan bentuk hasil yang diperlukan.

T

Tugas

Apa yang A.I perlu buat?

K

Konteks

Apakah situasi dan maklumat berkaitan?

T

Tujuan

Untuk siapa atau untuk apa hasil digunakan?

F

Format

Mahu jawapan dalam bentuk apa?

Ubah data sekali → Jadual, statistik dan graf berubah bersama. Setiap web app mesti menggunakan satu array JavaScript bernama data sebagai satu-satunya sumber data.

Eksperimen: Ubah Data, Lihat Graf Berubah

1

Buka kod HTML yang dijana.

2

Cari array JavaScript bernama data.

3

Ubah satu nilai nombor dalam array sahaja.

4

Simpan fail dan muat semula browser.

5

Perhatikan jadual, jumlah perhatian, warna baris dan graf berubah bersama.

🧤

Contoh: Sarung Tangan M — ubah Kuantiti daripada 7 kepada 14. Selepas muat semula, rekod tersebut tidak lagi dianggap stok rendah dan nilai graf turut berubah.

Tampal terus dalam satu chat ChatGPT.

Hasilkan satu mini web app bertajuk “Mini Web App Stok Bahan Makmal” dalam satu fail HTML lengkap. Gunakan jadual data simulasi ini: | Nama Bahan | Kategori | Kuantiti | Unit | Paras Minimum | |---|---|---:|---|---:| | Reagen Hematologi | Reagen | 12 | botol | 5 | | Larutan Buffer | Larutan | 3 | botol | 5 | | Tiub EDTA | Bahan Guna Habis | 18 | pek | 10 | | Kit Ujian Rapid | Kit Diagnostik | 4 | kotak | 6 | | Minyak Imersi | Reagen | 2 | botol | 3 | | Slaid Kaca | Bahan Guna Habis | 25 | kotak | 10 | | Pewarna Giemsa | Reagen | 7 | botol | 4 | | Bekas Sampel | Bekas | 6 | pek | 8 | Peraturan perhatian: rekod perlu perhatian apabila Kuantiti kurang daripada Paras Minimum. Jumlah yang dijangka ialah 4. Keperluan: - Gunakan HTML, CSS dan JavaScript biasa dalam satu fail tanpa framework, API, server, database atau pemasangan. - Fail mesti boleh dibuka terus dalam browser dan mesra telefon. - Paparkan label “Data Simulasi untuk Latihan Sahaja”. - Simpan semua rekod dalam satu array JavaScript bernama const data = [...]. - Jadual, kad statistik dan graf mesti dijana daripada array data JavaScript yang sama. Apabila data dalam array ditambah, dibuang atau diubah, jadual, kiraan, status perhatian dan graf mesti berubah secara automatik. - Paparkan kad jumlah keseluruhan dan jumlah perlu perhatian. - Paparkan jadual dan warnakan keseluruhan baris perhatian dengan merah lembut. - Sediakan butang “Semua Bahan” dan “Perlu Perhatian”. - Hasilkan graf bar dinamik Kuantiti berbanding Paras Minimum bagi setiap bahan menggunakan HTML/CSS/JavaScript biasa. - Jangan tulis nombor statistik atau graf secara statik. - Berikan arahan ringkas untuk menyimpan fail sebagai stok-bahan-makmal.html dan membukanya dalam browser.

Prompt pembetulan

Semak semula kod HTML yang anda hasilkan. Pastikan: 1. Jadual, kad statistik, tapisan dan graf membaca daripada array data JavaScript yang sama. 2. Tiada nombor graf atau statistik yang ditulis secara statik. 3. Apabila data dalam array berubah, semua paparan berubah secara automatik. 4. Rekod yang perlu perhatian ditentukan menggunakan peraturan yang diberi. 5. Semua butang tapisan berfungsi. 6. Web app kekal dalam satu fail HTML. Berikan semula kod HTML lengkap yang telah diperbaiki.

Langkah kerja

  1. Tekan Salin Prompt.
  2. Tampal dalam ChatGPT dan hantar.
  3. Simpan kod sebagai stok-bahan-makmal.html.
  4. Buka fail dalam browser dan uji jadual, tapisan serta graf.
  5. Gunakan prompt pembetulan sekali jika perlu.

Hasil Kumpulan

  • Satu fail HTML yang boleh dibuka terus
  • 8 rekod daripada satu array data
  • Jadual, dua kad statistik dan graf dinamik
  • Dua butang tapisan berfungsi
  • Satu prompt utama dan satu prompt pembetulan

Checklist Ujian

  • Semua 8 bahan dipaparkan.
  • Empat rekod perhatian ditanda merah.
  • Jumlah perhatian ialah 4.
  • Butang Semua Bahan dan Perlu Perhatian berfungsi.
  • Graf membandingkan Kuantiti dengan Paras Minimum.
  • Ubah satu nilai dalam array: jadual, statistik dan graf berubah bersama.
  • Paparan sesuai pada telefon dan tiada data sebenar digunakan.

Gunakan jadual data simulasi ini: | Item PPE | Saiz | Kuantiti | Paras Minimum | Lokasi | |---|---|---:|---:|---| | Sarung Tangan | S | 18 | 10 | Stor Utama | | Sarung Tangan | M | 7 | 10 | Stor Utama | | Sarung Tangan | L | 4 | 10 | Makmal A | | Pelitup Muka | Standard | 25 | 15 | Stor Utama | | Apron Pakai Buang | Standard | 8 | 10 | Makmal B | | Pelindung Muka | Standard | 3 | 5 | Makmal A | | Penutup Kepala | Standard | 20 | 10 | Stor Utama | | Penutup Kasut | Standard | 6 | 10 | Makmal C | Peraturan perhatian: rekod perlu perhatian apabila Kuantiti kurang daripada Paras Minimum. Jumlah yang dijangka ialah 5. Keperluan: - Gunakan HTML, CSS dan JavaScript biasa dalam satu fail tanpa framework, API, server, database atau pemasangan. - Fail mesti boleh dibuka terus dalam browser dan mesra telefon. - Paparkan label “Data Simulasi untuk Latihan Sahaja”. - Simpan semua rekod dalam satu array JavaScript bernama const data = [...]. - Jadual, kad statistik dan graf mesti dijana daripada array data JavaScript yang sama. Apabila data dalam array ditambah, dibuang atau diubah, jadual, kiraan, status perhatian dan graf mesti berubah secara automatik. - Paparkan kad jumlah keseluruhan dan jumlah perlu perhatian. - Paparkan jadual dan warnakan keseluruhan baris perhatian dengan merah lembut. - Sediakan butang “Semua PPE” dan “Stok Rendah”. - Hasilkan graf bar dinamik Kuantiti berbanding Paras Minimum bagi setiap item PPE menggunakan HTML/CSS/JavaScript biasa. Label graf mesti membezakan saiz, contohnya “Sarung Tangan — M”. - Jangan tulis nombor statistik atau graf secara statik. - Berikan arahan ringkas untuk menyimpan fail sebagai stok-ppe.html dan membukanya dalam browser.

Prompt pembetulan

Semak semula kod HTML yang anda hasilkan. Pastikan: 1. Jadual, kad statistik, tapisan dan graf membaca daripada array data JavaScript yang sama. 2. Tiada nombor graf atau statistik yang ditulis secara statik. 3. Apabila data dalam array berubah, semua paparan berubah secara automatik. 4. Rekod yang perlu perhatian ditentukan menggunakan peraturan yang diberi. 5. Semua butang tapisan berfungsi. 6. Web app kekal dalam satu fail HTML. Berikan semula kod HTML lengkap yang telah diperbaiki.

Langkah kerja

  1. Tekan Salin Prompt.
  2. Tampal dalam ChatGPT dan hantar.
  3. Simpan kod sebagai stok-ppe.html.
  4. Buka fail dalam browser dan uji jadual, tapisan serta graf.
  5. Gunakan prompt pembetulan sekali jika perlu.

Hasil Kumpulan

  • Satu fail HTML yang boleh dibuka terus
  • 8 rekod daripada satu array data
  • Jadual, dua kad statistik dan graf dinamik
  • Dua butang tapisan berfungsi
  • Satu prompt utama dan satu prompt pembetulan

Checklist Ujian

  • Semua 8 rekod PPE dipaparkan.
  • Lima rekod perhatian ditanda merah.
  • Jumlah perhatian ialah 5.
  • Butang Semua PPE dan Stok Rendah berfungsi.
  • Graf membandingkan Kuantiti dengan Paras Minimum dan membezakan saiz.
  • Ubah Sarung Tangan M daripada 7 kepada 14: jadual, statistik dan graf berubah bersama.
  • Paparan sesuai pada telefon dan tiada data sebenar digunakan.
